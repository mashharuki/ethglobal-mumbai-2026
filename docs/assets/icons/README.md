# 構成図のアイコン

2026-11-06に[Lucide公式リポジトリ](https://github.com/lucide-icons/lucide/tree/main/icons)から取得したSVGを使用。パッケージの追加は不要で、取得したファイルはこのディレクトリに保存し、単体でも用途が伝わるよう`title`要素を追加している。

| ファイル | 用途 | 取得元 |
| --- | --- | --- |
| `smartphone.svg` | 各利用者のブラウザ | [SVG](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/smartphone.svg) |
| `server.svg` | 認証・中継API | [SVG](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/server.svg) |
| `at-sign.svg` | ENSによる仮名・権限 | [SVG](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/at-sign.svg) |
| `database.svg` | Arkivの公開登録 | [SVG](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/database.svg) |
| `wallet.svg` | Ethereum Sepoliaの預託資金 | [SVG](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/wallet.svg) |

図では色を`#15725A`、線幅を`1.4`に設定し、形状は保持している。Lucideの[ライセンス](https://lucide.dev/license)と取得した[LICENSE](LICENSE)を参照。LucideはISC、Feather由来の素材にはMITの条件が含まれる。概要のSVGとdraw.ioにもライセンス文を埋め込んでいる。

これらは役割を示す汎用アイコンであり、各社の公式ロゴではない。ENSの[ブランドページ](https://ens.domains/brand)はロゴ使用前のライセンス取得を求めているため、今回の図では汎用アイコンと通常のサービス名を使用した。スポンサーによる承認・提携を示す図ではない。

図の画像はすべてローカルに埋め込み済み。表示のために外部サイトへアクセスする必要はない。
