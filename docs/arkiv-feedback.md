# Arkivブースのフィードバックと採用方針

2026-11-06。ユーザーが持ち帰ったフィードバック：アイデアはユニーク。説明とUIを簡潔にし、2分のプレゼンではキャッチフレーズから始める。Web3版Tinderとして説明し、Arkiv + Swarmも検討する。

**説明用キャッチコピー：シークレットTinder — 写真より先に、共通点から。**

続けて「プロフィールを公開せずに相手を探し、本人が承認したAI Personaとの会話で、会う前のきっかけをつくる」と説明する。Tinderは比較表現であり、公式提携や製品名の確定を意味しない。『ルッキズムを解決した』『個人情報を一切送らない』『AIが相性を保証する』とは言わない。

| 指摘 | 反映 | 担当・完了判断 |
| --- | --- | --- |
| 2分で伝える | [120秒の台本](demo-script.md)。価値→画面→技術の役割→次の一歩 | T033。リハーサル120秒以内。提出動画2〜3分の条件とは分ける |
| UIを明快にする | 「条件を決める→非公開で照合→任意でAIと話す」。各画面の主操作は一つ。技術詳細は展開式 | T043。初見の人が目的、次の操作、公開/AI送信の違いを説明できるか記録 |
| キャッチコピーを先に | README・紹介文の冒頭を更新 | T031/T043。実装済み/合成/未接続を正しく表示 |
| Swarm併用 | 公開場面カードのカタログをArkiv、素材をSwarmに置く[条件付き案](../specs/001-private-dating/contracts/swarm-assets.md) | T044→T036。実upload/readと画面利用があれば追加応募 |
| 完成済みAIBotを活用 | Persona対話を任意P2に採用。親の認証・マッチ・申請へ接続 | T025〜T029。単体実装と親結合を別判定 |

公式にはArkiv + Swarm bonus（from scratch）は$500で、Arkivの本賞に上乗せ可能。同じ提供元枠なので3提供元の選択数を増やさない。両技術の有意味な併用と`arkiv/swarm.md`が必要。[公式条件](https://ethglobal.com/events/mumbai/prizes/arkiv)。既存の『Swarm対象外』を条件付き追加候補へ変更し、正式目標EF・ENS・Arkivは維持する。

段階A→B→Cの技術順は維持する。AIBotは単体デモの準備を独立に行えるが、未接続の親マッチングを動作済みとして見せない。ENS実装はユーザーの一時停止指示を維持し、今回の作業は仕様と発表準備に限定する。
