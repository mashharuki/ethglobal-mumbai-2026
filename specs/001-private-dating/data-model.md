# データモデル

銘柄キーは[許可リスト](contracts/settlement.md)のチェーンIDとトークンアドレスの組。金額はすべて原単位の非負整数、外部表現は10進文字列。期限判定は精算契約の時刻を正本とし、表示側でISTに変換する。

| 対象・一意性 | 主なフィールドと関連 | 所有・保持・検証 |
| --- | --- | --- |
| 登録版（仮名＋版） | ENS所有者、辞書版、公開ルート、証明鍵の版、公開参照、期限 | 公開。名前の移転後は新所有者の新規登録が必要。Arkivの消失を失効・通信エラーと区別。過去マッチは成立時の版へ固定 |
| 私的登録 | 項目別の値・乱数、許可趣味ビット列、本人の鍵 | 本人端末。職業・年齢帯の提示は端末内。復元データを利用者管理下で暗号化保存。端末紛失時の資金回復にはバックアップが必要 |
| 検索リース（ランダムID＋世代） | 一時鍵、登録版、失効時刻、接続状態 | 検索画面を開いている間だけ更新。退出・切断検知・期限で無効。照合の中間値は端末のみ、配信保留暗号文はリース終了で削除 |
| 招待・マッチ | 両登録版、二人の参加署名、ランダムな文脈、預託note、最短期限 | 意味のあるペア記録は二人の端末。招待→片側承諾→双方承諾・拘束確認待ち→両預託の拘束確定で成立。拒否・失効・競合のとき成立しない |
| 部屋とターン（資格＋revision） | 匿名の役割、双方の参加、共有テーマ、場面、選択、次の手番、生成世代 | 参加待ち→Aの手番→Bの手番→生成待ち→次のA。再送はactionIdで同じ結果。終了を終端とし遅い生成応答を破棄。モデルには全員が共有を認めた情報のみ |
| 対面意思・確認 | 対面希望、本人の対象項目、結果、署名 | ペア間の秘匿通信。希望は双方一致時のみ通知。対面の確認は問題なし／職業・年齢帯と責任者の選択。AIや運営への判定委任なし |
| 預託と受取権 | token、数量、入金ブロック時刻、期限（入金時刻＋7日）、権利者鍵、状態、乱数、消費印 | 未拘束→拘束→受取可能→受領済み。未拘束取消・期限返却の分岐は[精算契約](contracts/settlement.md)。公開送金への相関を本人に表示 |
| 受付済み操作（主体＋操作ID） | 入力ダイジェスト、世代、結果・取引参照 | 同一内容の再送だけを許容。外部書込後のタイムアウトは確認中に戻し、照合後に再試行。ログは操作種別・所要時間・失敗種別のみ |

資金期限・部屋終了後は一時資格とモデル入力履歴を削除対象にする。公開チェーン履歴の削除は約束しない。秘密noteの復元情報は全額受領まで保管し、検索終了や部屋削除から独立させる。
